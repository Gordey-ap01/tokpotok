# tokpotok

Личные заметки и каталог ссылок. Доступ с любого устройства + контекст для агента.

Аккаунт: [Gordey-ap01](https://github.com/Gordey-ap01)  
Репо: https://github.com/Gordey-ap01/tokpotok

## Как пользоваться

Агенту: `читай README.md, LINKS.md и AGENT.md в Gordey-ap01/tokpotok`.

Новые ссылки — в `LINKS.md` по шаблону.
Выжимки — в `NOTES/`.

## Структура

| файл | зачем |
|---|---|
| `README.md` | этот файл |
| `LINKS.md` | каталог полезных репо |
| `AGENT.md` | правила для ИИ-агента |
| `NOTES/` | выжимки |

Не класть сюда креды, токены, приватные ключи.
