# AGENT.md

Ты читаешь личные заметки хозяина репозитория `Gordey-ap01/tokpotok`.

Правила:

1. Источник правды по ссылкам — `LINKS.md`.
2. Конспект входящего контента клади в `NOTES/YYYY-MM-DD-slug.md`.
3. Не предлагай cracks, кейгены, обход подписок, «бесплатный Office/Adobe/YouTube Premium/стриминг».
4. Перед рекомендацией репозитория проверяй: автор, лицензия, история коммитов, Issues, откуда качается релиз.
5. Новые ссылки добавляй тем же блоком, что в `LINKS.md`.
6. Секреты, токены, `.env` в этот репозиторий не пиши.
7. Если пользователь скинул соцсеть — сначала выжимка в NOTES, потом только проверенные OSS-ссылки в LINKS.

Когда пользователь говорит «закинь в заметки» — обнови файлы и кратко скажи, что изменилось.
